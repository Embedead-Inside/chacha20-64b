# chacha20-64b

[![License: MIT-0](https://img.shields.io/badge/License-MIT--0-blue.svg)](https://spdx.org/licenses/MIT-0.html)
[![Language: C99](https://img.shields.io/badge/Language-C99-green.svg)](#)

ベアメタル環境やリソース制限の厳しい組込みシステム向けに最適化された、超軽量かつ最高速の **ChaCha20** ストリーム暗号実装です。

OSや動的なメモリ割り当て（`malloc`）を一切排除し、**64バイト固定ブロックによるインプレース（同一メモリ上での直接上書き）暗号化・復号**を実現しています。

---

## 特徴 (Features)

* **ゼロ・ルックアップテーブル**: Sボックスなどの置換テーブルを持たないため、RAM/フラッシュの消費を最小限に抑え、キャッシュタイミング攻撃に対して強靭です。
* **完全なインプレース処理**: 入力バッファをその場で直接書き換えるため、メモリ帯域の無駄な消費やデータコピーのオーバーヘッドがありません。
* **完全アンロール & ループ排除**: 分岐予測ミスをゼロにし、CPUパイプラインを最大限に活かすことで極限の処理速度を発揮します。
* **初期化と変換の分離**: 鍵（Key）とナンス（Nonce）の事前計算を独立させることで、複数ブロック処理時の重複計算を完全に排除しています。
* **64バイト固定ユニット**: センサーデータや通信パケットに最適な64バイト単位で設計されており、256バイトなどの複数ブロックも直列呼び出しで高速に処理可能です。
* **ゼロ依存性**: C99標準のプリミティブ（`stdint.h`）のみで記述されており、外部ライブラリを一切必要としません。

## 使い方 (Usage)

### 基本的な使用例（256バイト・4ブロック処理）

```c
#include "chacha20_64b.h"
#include <stdint.h>

void process_packet_256bytes(uint8_t packet[256], const uint8_t key[32], const uint8_t nonce[12]) {
    chacha20_64b_ctx_t ctx;
    
    // 1. 初期化（ベース状態の事前計算）は最初に1回だけ実行
    chacha20_64b_init(&ctx, key, nonce);

    // 2. 64バイト単位でカウンタを増やしながらインプレース変換
    // 暗号化・復号ともに全く同じ関数を呼び出すことで完了します
    chacha20_64b_transform(packet + 0,   &ctx, 0); // ブロック 0 (カウンター: 0)
    chacha20_64b_transform(packet + 64,  &ctx, 1); // ブロック 1 (カウンター: 1)
    chacha20_64b_transform(packet + 128, &ctx, 2); // ブロック 2 (カウンター: 2)
    chacha20_64b_transform(packet + 192, &ctx, 3); // ブロック 3 (カウンター: 3)
}
```

## API 仕様 (API Reference)

### `chacha20_64b_init`
```c
void chacha20_64b_init(chacha20_64b_ctx_t *ctx, const uint8_t key[32], const uint8_t nonce[12]);
```
* **説明**: キーとナンスから、ブロック変換で共通となるベース状態を生成してコンテキストに格納します。
* **引数**:
  * `ctx`: 初期化対象のコンテキスト構造体へのポインタ
  * `key`: 32バイト（256ビット）の秘密鍵
  * `nonce`: 12バイト（96ビット）のナンス

### `chacha20_64b_transform`
```c
void chacha20_64b_transform(uint8_t buf[64], const chacha20_64b_ctx_t *ctx, uint32_t counter);
```
* **説明**: 64バイトのデータバッファをその場で直接XOR変換（インプレース暗号化/復号）します。
* **引数**:
  * `buf`: 処理対象の64バイトバッファ（入力データが暗号文/平文へ直接更新されます）
  * `ctx`: 初期化済みのコンテキスト構造体
  * `counter`: このブロックで使用する32ビットカウンター値（0, 1, 2...）
